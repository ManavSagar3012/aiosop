# Red Team Phishing Simulation

## Procedures

### Step 1: Campaign Planning & Target Scoping
- Define the objectives and scope of the phishing simulation.
- Gather target information (e.g., employee names, emails) using OSINT techniques.
- Select or design realistic phishing scenarios based on current threat actor TTPs.

### Step 2: Infrastructure & Template Design
- Set up the phishing infrastructure using tools like GoPhish.
- Configure SMTP sending profiles and verify domain reputation and mail delivery.
- Create convincing email templates and landing pages with tracking capabilities.

### Step 3: Execution & Real-time Monitoring
- Launch the phishing campaign and monitor real-time engagement metrics.
- Track email open rates, link click-through rates, and credential submission rates.
- Identify and document successful captures while ensuring data privacy and safety.

### Step 4: Analysis & Security Awareness Reporting
- Analyze the results to identify departments or individuals most susceptible to phishing.
- Generate comprehensive reports for security leadership and HR teams.
- Provide actionable recommendations for improving security awareness training and controls.
